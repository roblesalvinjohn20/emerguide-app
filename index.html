Install in three steps

  1. Download the file

    Tap the download button on your Android phone. If your browser warns that the file type can be harmful, choose Download anyway.

  2. Allow the install

    Open the file. When Android asks, turn on Allow from this source for your browser. You only do this once.

  3. Tap Install

    Wait a few seconds, then tap Open. The app is ready to use.
